RAG 企业知识库问答系统 — 项目启动步骤
====================================================

前提条件
--------
- Python 3.10+
- Node.js 18+
- Docker Desktop（需运行中）
- DeepSeek API Key

启动步骤
--------

1. 启动基础设施（Docker）
   cd D:\RAG1.0
   docker compose up -d

   说明：启动 etcd + MinIO + Milvus 三个容器，数据持久化在 Docker volumes 中。

2. 配置环境变量
   复制模板文件并编辑：
   cp .env.example .env
   然后用文本编辑器打开 .env，填入 DEEPSEEK_API_KEY 参数。

3. 启动后端
   cd D:\RAG1.0\backend

   # 首次运行：创建虚拟环境并安装依赖
   python -m venv venv

   # 激活虚拟环境（Windows PowerShell）
   venv\Scripts\activate

   # 安装依赖
   pip install -r requirements.txt

   # 启动后端服务
   SKIP_MODELS=0 uvicorn app.main:app --reload --port 8000

   说明：
   - 首次运行会自动从 HuggingFace 下载模型到 cache/ 目录（BGE-M3、BGE-Reranker-v2-M3）
   - 如果只想启动 API（不加载 embedding/reranker 模型），设置 SKIP_MODELS=1
   - 服务运行在 http://localhost:8000
   - API 文档地址：http://localhost:8000/docs

4. 启动前端
   cd D:\RAG1.0\frontend

   # 首次运行：安装依赖
   npm install

   # 启动开发服务器
   npm run dev

   说明：前端运行在 http://localhost:5173

5. 验证服务
   - 打开浏览器访问 http://localhost:5173
   - 在文档管理页面上传文档（支持 PDF、DOCX、TXT）
   - 在问答页面输入问题，测试 RAG 检索和回答

常用命令
--------
- 停止 Docker 容器： docker compose down
- 查看 Docker 容器状态： docker compose ps
- 查看后端日志： 终端运行 uvicorn 时会直接输出

技术栈
--------
- 前端：Vue 3 + Vite + Element Plus
- 后端：FastAPI + LangChain
- 向量数据库：Milvus（依赖 etcd + MinIO）
- 嵌入模型：BGE-M3（dense + sparse 双向量）
- 重排序模型：BGE-Reranker-v2-M3
- LLM：DeepSeek API

端口占用
--------
- 5173 — 前端开发服务器
- 8000 — 后端 API
- 19530 — Milvus gRPC
- 9091 — Milvus 监控指标
- 9000 — MinIO API
- 9001 — MinIO 控制台
